# 휴가 Import 실제 운영 반영 전 체크리스트

실제 운영 엑셀 파일을 production 서비스에 반영하기 전 OWNER가 완료해야 하는 체크리스트입니다.

## 운영 환경

- [ ] Vercel production 배포가 정상 상태다.
- [ ] 운영 Neon DB migration이 적용되어 있다.
- [ ] OWNER 계정으로 로그인할 수 있다.
- [ ] `/admin/leaves/import`에 접근할 수 있다.
- [ ] Step-up 재인증이 동작한다.
- [ ] 구성원 휴가 현황 화면에 접근할 수 있다.
- [ ] LeaveLedger 기준 휴가 현황이 정상 표시된다.
- [ ] AuditLog 화면에 접근할 수 있다.

## 파일 확인

- [ ] 업로드 파일이 최신 파일인지 확인했다.
- [ ] 월별 연차 사용 내역 파일과 상세 휴가 사용 내역 파일이 구분되어 있다.
- [ ] 월별 파일에 필요한 컬럼이 모두 있다.
- [ ] 상세 파일에 필요한 컬럼이 모두 있다.
- [ ] 실제 개인정보 엑셀 원본을 GitHub에 저장하지 않았다.
- [ ] 실제 개인정보 엑셀 원본을 public 폴더에 저장하지 않았다.

## Preview 확인

- [ ] 직원 사번, 이름, 회사내이름이 시스템 직원과 매칭된다.
- [ ] 미매칭 row가 없다.
- [ ] 중복 의심 row를 확인했다.
- [ ] UNKNOWN 상태 row가 없다.
- [ ] 휴가취소 row가 사용량으로 차감되지 않는다.
- [ ] 승인대기 row가 used가 아니라 pending으로 반영된다.
- [ ] 엑셀 잔여 연차와 시스템 잔여 연차 차이를 확인했다.
- [ ] 반영 예정 row 수를 확인했다.
- [ ] 반영 제외 row 수를 확인했다.
- [ ] 생성 예정 LeaveRequest 수를 확인했다.
- [ ] 생성 예정 LeaveLedger 수를 확인했다.
- [ ] 생성 예정 LeaveAdjustment 수를 확인했다.

## 최종 반영 준비

- [ ] 상세 휴가 사용 내역 파일을 먼저 반영한다.
- [ ] 상세 반영 후 월별 연차 사용 내역 파일을 업로드한다.
- [ ] 월별 파일은 상세 반영 후 시스템 잔여와 비교한다.
- [ ] 차이가 있는 직원만 조정 대상인지 확인했다.
- [ ] Step-up 재인증 가능 여부를 확인했다.
- [ ] 반영 후 직원별 휴가 현황을 확인할 준비가 되어 있다.
- [ ] AuditLog 확인 준비가 되어 있다.

## 반영 후 확인

- [ ] batch 상태가 `APPLIED`인지 확인한다.
- [ ] 같은 batch 재반영이 차단되는지 확인한다.
- [ ] 직원별 휴가 현황에서 잔여 연차를 확인한다.
- [ ] 상세 파일의 취소 row가 사용량으로 차감되지 않았는지 확인한다.
- [ ] 승인대기 row가 pending으로 표시되는지 확인한다.
- [ ] AuditLog에 import 반영 기록이 남았는지 확인한다.
- [ ] AuditLog에 엑셀 row 원문 전체, token, secret, 주민등록번호, 계좌번호가 없는지 확인한다.
