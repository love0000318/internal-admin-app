# 직원 온보딩 안내문

이 문서는 직원에게 사내 관리 서비스 가입과 첫 사용 방법을 안내하기 위한 메시지 초안이다. 실제 초대 링크와 가입 인증 코드는 직원별로 다르며, 공개 채널에 공유하지 않는다.

## 서비스 소개

Internal Ops는 회사 내부 운영을 위한 사내 관리 서비스다. 직원은 이 서비스에서 내 휴가 보유 현황을 확인하고, 휴가를 요청하며, 승인 상태와 알림을 확인할 수 있다. 근태 기능을 운영에 포함한 경우 출근/퇴근 기록과 근태 이력도 확인할 수 있다.

## 가입 방법

1. 총괄 관리자가 전달한 초대 링크에 접속한다.
2. 함께 전달받은 1회용 가입 인증 코드를 입력한다.
3. 이름, 전화번호, 비밀번호를 입력해 가입을 완료한다.
4. 가입 인증 코드는 한 번만 사용할 수 있으며, 가입 완료 후 재사용할 수 없다.

## 로그인 방법

가입 후 production URL에 접속해 전화번호와 비밀번호로 로그인한다.

운영 URL:

```txt
https://interal-admin-app.vercel.app
```

공용 PC에서는 `이 기기에서 자동 로그인 유지`를 선택하지 않는 것을 권장한다. 로그아웃하면 자동 로그인 유지도 해제된다.

## 휴가 요청 방법

1. 로그인 후 `내 휴가` 화면으로 이동한다.
2. 보유 휴가와 잔여 수량을 확인한다.
3. `휴가 요청`에서 휴가 유형, 날짜, 반차 여부, 사유를 입력한다.
4. 제출 후 승인 상태를 확인한다.
5. 승인/반려 결과는 알림센터에서 확인할 수 있다.

## 출근/퇴근 기록 방법

근태 기능이 이번 운영 범위에 포함된 경우 다음 절차를 따른다.

1. `/attendance` 화면으로 이동한다.
2. 출근 시 `출근` 버튼을 누른다.
3. 퇴근 시 `퇴근` 버튼을 누른다.
4. `/attendance/history`에서 내 근태 이력을 확인한다.

근태 메뉴가 보이지 않거나 접속되지 않으면 관리자에게 문의한다.

## 알림 확인 방법

로그인 후 우측 상단 알림 아이콘을 누르면 알림센터로 이동한다. 읽지 않은 알림이 있으면 빨간 표시가 보인다.

## 모바일 사용 안내

모바일 브라우저에서도 로그인, 초대 가입, 휴가 요청, 알림 확인을 사용할 수 있다. 화면이 깨지거나 버튼이 보이지 않으면 사용 중인 기기, 브라우저, 화면 스크린샷을 관리자에게 전달한다.

## 직원에게 보낼 메시지 예시

```txt
안녕하세요.

사내 관리 서비스 가입 안내드립니다.

아래 초대 링크로 접속해 가입을 완료해 주세요.

초대 링크:
{초대 링크}

가입 인증 코드:
{가입 인증 코드}

가입 후에는 다음 기능을 사용할 수 있습니다.

- 내 휴가 보유 현황 확인
- 휴가 요청
- 휴가 승인 상태 확인
- 알림 확인
- 출근/퇴근 기록, 근태 기능 운영 시

가입 인증 코드는 1회만 사용할 수 있으니 외부에 공유하지 말아 주세요.
공용 PC에서는 자동 로그인 유지를 선택하지 않는 것을 권장합니다.

문의:
{문의처}
```

## 문의처

운영자는 실제 문의 채널을 아래에 적어 직원에게 전달한다.

```txt
문의처: {담당자 이름 / 연락 채널}
```
