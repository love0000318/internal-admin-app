# 직원 첫 사용 가이드

직원이 초대 링크를 받고 처음 가입한 뒤 휴가를 요청하는 방법입니다.

## 1. 초대 링크 받기

대표 또는 운영 담당자가 전달한 초대 링크를 엽니다. 초대 링크는 한 번만 사용할 수 있습니다.

## 2. 회원가입

1. 이름을 입력합니다.
2. 전화번호를 입력합니다.
3. 비밀번호를 입력합니다.
4. 비밀번호 확인을 입력합니다.
5. 본인인증 또는 운영자가 안내한 확인 절차를 완료합니다.

## 3. 전화번호로 로그인

가입 후 `/login`에서 전화번호와 비밀번호로 로그인합니다.

## 4. 대시보드 확인

대시보드에서 본인 이름, 직급, 역할, 소속 팀을 확인합니다.

## 5. 내 휴가 보유 현황 확인

`휴가 보유 현황 및 요청` 메뉴에서 다음을 확인합니다.

- 총 부여 휴가
- 사용 완료 휴가
- 승인 대기 중 휴가
- 사용 가능 잔여 휴가

## 6. 연차 요청하기

1. 새 휴가 요청을 선택합니다.
2. 휴가 유형을 `연차`로 선택합니다.
3. 시작일과 종료일을 선택합니다.
4. 사유를 입력합니다.
5. 요청 일수를 확인하고 제출합니다.

## 7. 반차 요청하기

1. 휴가 유형을 `반차`로 선택합니다.
2. 하루 날짜를 선택합니다.
3. 오전 또는 오후를 선택합니다.
4. 요청 일수가 0.5일인지 확인합니다.

## 8. 예비군/병가/경조사 요청하기

정책에 따라 증빙 URL이 필요할 수 있습니다. 증빙이 필요하다고 표시되면 안내받은 증빙 자료 링크를 입력합니다.

## 9. 승인 상태 확인하기

휴가 요청 목록에서 상태를 확인합니다.

- 승인 대기
- 승인 완료
- 반려
- 취소
- 철회

## 10. 승인 대기 요청 철회하기

상태가 `승인 대기`인 요청만 철회할 수 있습니다. 승인 완료된 휴가는 직접 철회할 수 없고 관리자에게 문의해야 합니다.

## 11. 로그인 문제 발생 시 문의할 내용

운영 담당자에게 다음 정보를 전달합니다.

- 입력한 전화번호
- 이름
- 초대 링크 가입 여부
- 화면에 표시된 오류 문구
# 휴가 증명자료 제출

- 예비군처럼 요청 전 증명자료가 필요한 휴가는 휴가 요청 화면에서 파일을 함께 제출해야 합니다.
- 병가처럼 요청 후 제출이 가능한 휴가는 먼저 요청을 만들고, 내 휴가 요청 상세 화면에서 증명자료를 추가 제출합니다.
- 증명자료가 반려되거나 재제출 요청을 받으면 알림을 확인한 뒤 같은 상세 화면에서 새 파일을 제출합니다.
- 증명자료 제출은 실제 휴가 요청과 연결되며, 파일은 공개 링크가 아니라 인증된 화면을 통해서만 확인됩니다.
