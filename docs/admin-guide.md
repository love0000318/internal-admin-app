# 관리자 가이드

OWNER와 LEAD가 운영 중 사용하는 기능을 정리합니다.

## 1. 권한 요약

- OWNER: 조직/직원, 휴가 정책, 회사 휴일, 휴가 조정, 모든 휴가 승인/반려/취소, 감사 로그 조회 가능.
- LEAD: 자신이 관리하는 팀과 하위 팀 직원의 휴가 요청만 승인/반려/취소 가능.
- LEAD는 자기 자신의 휴가 요청을 승인/반려/취소할 수 없습니다.

## 2. 조직 관리

OWNER는 `조직 구성 및 직원 초대` 메뉴에서 팀과 직원을 관리합니다.

1. `/organization/teams`에서 팀을 생성합니다.
2. 상위 팀과 팀 리드를 지정할 수 있습니다.
3. 팀을 삭제하지 말고 비활성화합니다.
4. ACTIVE 직원이 있는 팀을 비활성화할 수 있지만 AuditLog에 기록됩니다.

## 3. 직원 초대

1. `/organization/invitations`로 이동합니다.
2. 이름, 이메일, 직급, 역할, 팀, 입사일, 생일을 입력합니다.
3. 직원 초대 role은 LEAD 또는 MANAGER만 선택합니다.
4. 생성된 초대 링크를 복사해 직원에게 전달합니다.
5. 실제 이메일 발송은 MVP에서 제공하지 않습니다.

## 4. 직원 수정과 비활성화

1. `/organization/employees`에서 직원을 선택합니다.
2. 이름, 직급, role, 팀, 입사일, 생일, 상태를 수정합니다.
3. 자기 자신을 비활성화할 수 없습니다.
4. 마지막 OWNER는 비활성화하거나 권한 강등할 수 없습니다.
5. 직원 삭제는 hard delete가 아니라 `DEACTIVATED` 상태 변경입니다.

## 5. 휴가 정책 설정

OWNER는 `/admin/leaves/settings`에서 휴가 유형별 정책을 수정합니다.

- 연차 차감 여부
- 증빙 필요 여부
- 연간 최대 사용일
- 사용 여부

정책 변경은 AuditLog에 기록됩니다.

## 6. 회사 휴일 등록

OWNER는 `/admin/leaves/holidays`에서 회사 휴일을 등록합니다.

- 휴일은 휴가 일수 계산에서 제외됩니다.
- 과거 계산 정합성을 위해 삭제 대신 비활성화합니다.

## 7. 직원별 휴가 조정

OWNER는 `/admin/leaves/balances`에서 직원별 연도 휴가 조정을 추가합니다.

- 조정 일수는 양수/음수 모두 가능합니다.
- 조정 사유는 필수입니다.
- 모든 조정은 AuditLog에 기록됩니다.

## 8. 휴가 승인

OWNER/LEAD는 `휴가 승인 요청 사항`에서 PENDING 요청을 처리합니다.

1. `/leaves/approvals`에서 승인 대기 요청을 확인합니다.
2. 상세 화면에서 요청자, 기간, 일수, 사유, 증빙을 확인합니다.
3. 승인 시 잔여 휴가를 승인 시점에 다시 검증합니다.
4. 반려 시 반려 사유가 필수입니다.
5. `/leaves/approvals/approved`에서 승인 완료 휴가를 취소할 수 있습니다.
6. 승인 취소 시 취소 사유가 필수입니다.

## 9. 감사 로그

OWNER는 `/admin/audit-logs`에서 주요 변경 이력을 조회합니다.

민감정보는 화면에서 마스킹됩니다. password hash, token hash, session token, 첨부 URL 등은 표시하지 않습니다.
