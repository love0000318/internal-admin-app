# 직원 초대 Rollout 체크리스트

직원 오픈은 단계적으로 진행한다.

```txt
1단계: 대표 + 테스트 직원 1~2명
2단계: 핵심 운영 직원 3~5명
3단계: 전체 직원
```

각 단계마다 초대, 가입, 로그인, 모바일 사용, 휴가 요청, 알림 확인을 검수한다. 근태 기능을 오픈 범위에 포함한 경우 출근/퇴근도 함께 확인한다.

## 초대 전 확인

- [ ] 직원 이름 확인
- [ ] 직원 이메일 또는 연락처 확인
- [ ] 소속 팀 확인
- [ ] 역할 확인: OWNER, LEAD, MANAGER, EXTERNAL_PARTNER
- [ ] 입사일 확인
- [ ] 휴가 기준 확인
- [ ] 생일 정보 확인, 생일 반차를 사용할 경우
- [ ] 직원에게 전달할 문의처 확인
- [ ] 초대 전달 채널 확인

## 초대 생성 후 확인

- [ ] 단축 초대 URL 생성 여부
- [ ] 1회용 가입 인증 코드 생성 여부
- [ ] 초대 링크와 인증 코드 복사 여부
- [ ] 직원에게 전달 완료 여부
- [ ] 초대 만료일 확인
- [ ] 초대 링크와 인증 코드를 공개 채널에 공유하지 않았는지 확인
- [ ] 초대 상태가 PENDING인지 확인

## 직원 가입 후 확인

- [ ] 가입 완료 여부
- [ ] 직원 상태 ACTIVE 여부
- [ ] 소속 팀 반영 여부
- [ ] 역할 반영 여부
- [ ] 휴가 보유 현황 확인
- [ ] 모바일 접속 가능 여부
- [ ] 알림센터 접근 가능 여부
- [ ] 근태 화면 접근 가능 여부, 근태 기능을 운영하는 경우
- [ ] 첫 로그인 완료 여부

## 단계별 완료 기준

### 1단계

- [ ] 테스트 직원이 초대 링크에 접속했다.
- [ ] 가입 인증 코드 입력이 성공했다.
- [ ] 로그인에 성공했다.
- [ ] 모바일에서 주요 화면을 확인했다.
- [ ] 휴가 요청이 가능했다.
- [ ] 알림센터 확인이 가능했다.
- [ ] 출근/퇴근이 가능했다, 근태 포함 시.

### 2단계

- [ ] 핵심 운영 직원 3~5명이 가입했다.
- [ ] 문의 유형을 기록했다.
- [ ] 휴가 요청/승인 흐름이 정상이다.
- [ ] 모바일 사용성 blocker가 없다.
- [ ] 관리자 운영자가 초대 상태를 추적할 수 있다.

### 3단계

- [ ] 전체 직원 대상 안내문이 준비되었다.
- [ ] 운영 문의 담당자가 지정되었다.
- [ ] 첫 주 모니터링 문서가 준비되었다.
- [ ] 장애 대응 runbook을 운영자가 숙지했다.
