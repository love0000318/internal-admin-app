# 휴가 승인 정책 운영 절차

## 설정 순서

1. OWNER로 로그인한다.
2. `/admin/leaves/approval-policies`에 접속한다.
3. 승인 정책을 생성한다.
4. 승인 방식과 승인자 규칙을 선택한다.
5. 반려/취소 사유 필수 여부를 설정한다.
6. 증명자료 검수가 필요한 정책은 `증명자료 확인 후 승인`을 켠다.
7. 휴가 유형별로 정책을 연결한다.
8. 테스트 직원으로 휴가 요청을 생성해 자동 승인 또는 승인 대기 상태를 확인한다.

## 운영 원칙

- 기본 휴가 유형은 `담당 리드 또는 OWNER` 승인 정책으로 시작한다.
- 자동 승인 정책은 실제 운영 전 대표가 대상 휴가 유형을 확인한 뒤 적용한다.
- 순차 승인은 현재 실제 처리 흐름이 아니며 후속 개발 범위다.
- 요청자 본인은 자기 휴가를 직접 승인할 수 없다.
- 정책 변경은 변경 이후 생성되는 요청부터 적용하는 것을 원칙으로 한다.
- `증명자료 확인 후 승인` 정책은 승인 화면 경고뿐 아니라 서버 액션에서도 차단한다.
