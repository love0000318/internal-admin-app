# 일일 운영 점검표

직원 오픈 후 첫 주에는 매일 확인하고, 안정화 후에는 운영 상황에 맞게 주기를 조정한다.

## 가입/계정

- [ ] 신규 가입 실패 문의 확인
- [ ] 초대 만료/재발급 요청 확인
- [ ] 가입 인증 코드 오류 문의 확인
- [ ] 첫 로그인 실패 문의 확인
- [ ] 비활성 직원 여부 확인
- [ ] 권한/팀/역할 오류 문의 확인

## 휴가

- [ ] 승인 대기 휴가 확인
- [ ] 반려/취소 요청 확인
- [ ] 휴가 잔여 이상 여부 확인
- [ ] 생일 반차/맞춤휴가 표시 이상 여부 확인
- [ ] 증명자료 제출/재제출 문의 확인

## 근태

근태 기능을 운영 범위에 포함한 경우:

- [ ] 미출근자 확인
- [ ] 퇴근 누락자 확인
- [ ] 중복 출근 문의 확인
- [ ] 근태 수정 요청 확인

근태 기능이 제외된 경우:

- [ ] 근태 제외 안내가 필요한 직원 문의 확인

## 알림/보안

- [ ] 알림센터 오류 문의 확인
- [ ] AuditLog 고위험 이벤트 확인
- [ ] 보안 대시보드 확인
- [ ] Step-up 실패 이벤트 확인
- [ ] 비인가 접근 차단 이벤트 확인

## 시스템

- [ ] Vercel 오류 여부 확인
- [ ] Neon DB 오류 여부 확인
- [ ] 외부 알림 실패 여부 확인
- [ ] Cron/JobRun 실패 여부 확인
- [ ] 직원 피드백 기록
- [ ] 다음 조치 담당자 지정
