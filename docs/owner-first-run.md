# 대표 첫 실행 가이드

대표가 서비스를 처음 열고 실제 운영을 시작하기 위한 순서입니다.

## 1. 서비스 주소 접속

운영 담당자가 전달한 서비스 주소를 엽니다.

예:

```text
https://your-domain.com
```

## 2. OWNER 초대 링크 접속

운영 담당자가 전달한 OWNER 초대 링크를 엽니다. 이 링크는 한 번만 사용할 수 있으므로 외부에 공유하지 마세요.

## 3. 대표 계정 생성

1. 이름을 입력합니다.
2. 전화번호를 입력합니다.
3. 비밀번호를 입력합니다.
4. 비밀번호 확인을 입력합니다.
5. 본인인증 또는 운영자가 안내한 확인 절차를 완료합니다.

가입이 완료되면 대시보드로 이동합니다.

## 4. 첫 로그인

다음부터는 `/login`에서 전화번호와 비밀번호로 로그인합니다.

## 5. 대시보드 확인

대시보드에서 다음이 맞는지 확인합니다.

- 이름
- 직급
- 역할: 총괄 관리자
- 내 휴가 요약
- 승인 대기 휴가 요청 요약

## 6. 조직/팀 생성

1. `조직 구성 및 직원 초대` 메뉴로 이동합니다.
2. `조직/팀 관리`에서 회사 조직 또는 테스트팀을 만듭니다.
3. 필요한 경우 상위 팀을 선택합니다.

## 7. 리드 직원 초대

1. 직원 초대 화면으로 이동합니다.
2. 이름: 테스트리드
3. 직급: 리드
4. 역할: LEAD
5. 소속 팀: 테스트팀
6. 초대 링크를 복사해 직원에게 전달합니다.

## 8. 매니저 직원 초대

1. 이름: 테스트매니저
2. 직급: 매니저
3. 역할: MANAGER
4. 소속 팀: 테스트팀
5. 초대 링크를 복사해 직원에게 전달합니다.

## 9. 직원 가입 확인

직원이 초대 링크로 가입한 뒤 직원 목록에서 상태가 `활성`인지 확인합니다.

## 10. 휴가 정책 확인

`휴가 관리 설정`에서 연차, 반차, 예비군, 병가, 경조사 정책을 확인합니다.

## 11. 회사 휴일 등록

`회사 휴일 관리`에서 회사 휴일을 등록합니다. 등록된 휴일은 휴가 일수 계산에서 제외됩니다.

## 12. 직원 휴가 요청 테스트

테스트매니저가 연차 또는 반차를 요청하도록 안내합니다.

## 13. 휴가 승인 테스트

`휴가 승인 요청 사항`에서 직원의 요청을 승인합니다. 승인 완료 목록과 직원의 잔여 휴가를 확인합니다.

## 14. 감사 로그 확인

`감사 로그` 메뉴에서 다음 기록이 있는지 확인합니다.

- 직원 초대
- 직원 가입
- 팀 생성
- 휴가 요청
- 휴가 승인

## 15. 사용 시작 전 마지막 확인

- 대표 계정으로 다시 로그인할 수 있는지 확인합니다.
- 직원이 로그인할 수 있는지 확인합니다.
- MANAGER가 관리자 메뉴에 접근할 수 없는지 확인합니다.
- 휴가 승인/반려/취소가 정상 동작하는지 확인합니다.
