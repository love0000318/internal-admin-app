# LEAD 휴가 승인 가이드

LEAD는 담당 팀과 하위 팀 직원의 휴가 요청만 처리할 수 있습니다. 자기 자신의 휴가 요청은 직접 승인, 반려, 승인 취소할 수 없으며 OWNER가 처리해야 합니다.

## 1. 접근 범위

- LEAD는 `/leaves/approvals`에서 담당 범위 안의 요청만 확인합니다.
- 담당 팀 또는 하위 팀 밖 직원의 요청은 목록과 상세 화면에서 접근할 수 없습니다.
- URL을 직접 입력해도 서버 권한 검사에서 차단됩니다.
- EXTERNAL_PARTNER는 내부 휴가 기능에 접근할 수 없습니다.

## 2. 승인 정책 반영

2차 휴가 고도화 8단계부터 휴가 유형별 승인 정책이 적용됩니다.

- `TEAM_LEAD`: 담당 LEAD가 승인할 수 있으며 OWNER도 전체 관리자 권한으로 처리할 수 있습니다.
- `TEAM_LEAD_OR_OWNER`: 담당 LEAD 또는 OWNER가 승인할 수 있습니다.
- `OWNER`: OWNER만 승인할 수 있으므로 LEAD는 처리할 수 없습니다.
- `CUSTOM_USER`: 지정 승인자 또는 OWNER가 처리합니다. LEAD가 지정 승인자가 아니면 처리할 수 없습니다.
- `NONE`: 요청 생성 시 자동 승인됩니다.

상세 화면의 “승인 정책” 영역에서 현재 요청의 정책명, 승인 방식, 승인자 규칙, 증명자료 확인 필요 여부를 확인합니다.

## 3. 승인 처리

1. LEAD 계정으로 로그인합니다.
2. `/leaves/approvals`로 이동합니다.
3. 담당 범위 안의 PENDING 요청을 선택합니다.
4. 요청 기간, 휴가 유형, 요청 수량, 사유, 증명자료 상태를 확인합니다.
5. 승인 가능한 정책이면 승인 버튼을 눌러 처리합니다.

증명자료 확인 후 승인 정책이 켜진 휴가 유형은 증명자료 상태가 `ACCEPTED`가 되기 전까지 승인할 수 없습니다.

## 4. 반려와 승인 취소

- 반려 사유 필수 정책이 켜진 요청은 반려 사유를 반드시 입력해야 합니다.
- 승인 취소 사유 필수 정책이 켜진 요청은 취소 사유를 반드시 입력해야 합니다.
- 정책에서 사유 필수를 끄면 사유 없이 처리할 수 있지만, 운영상 가능한 한 사유를 남기는 것을 권장합니다.

## 5. 증명자료 검수

- 담당 범위 안의 요청에 첨부된 증명자료만 확인할 수 있습니다.
- 담당 범위 밖 직원 또는 자기 자신의 요청 증명자료는 검수할 수 없습니다.
- 증명자료는 인증된 다운로드 route를 통해서만 열립니다.
- 반려 또는 재제출 요청 시 직원이 이해할 수 있는 사유를 입력해야 합니다.

## 6. 권한 문제가 있을 때 확인할 것

- 본인 계정의 role이 `LEAD`인지 확인합니다.
- OWNER가 팀 관리 화면에서 담당 팀을 올바르게 지정했는지 확인합니다.
- 직원이 올바른 팀에 소속되어 있는지 확인합니다.
- 휴가 유형의 승인 정책이 `OWNER` 또는 `CUSTOM_USER`로 지정되어 있지 않은지 확인합니다.
