## 상태 값 예시

- 대기
- 완료
- 실패
- 재발급 필요
- 문의 접수
- 제외

## 문제 기록 원칙

- 직원이 겪은 증상만 간단히 기록한다.
- 초대 링크, 인증 코드, token, password는 기록하지 않는다.
- 화면 오류는 screenshot을 별도 보안 채널로 전달받고 공개 문서에는 첨부하지 않는다.
