# 휴가 캘린더 권한 범위 가이드

## 권한별 표시 범위

- OWNER: 전체 활성 내부 구성원의 승인된 휴가를 볼 수 있다.
- LEAD: 본인이 담당자로 지정된 팀과 모든 하위 팀 구성원의 승인된 휴가를 볼 수 있다.
- MANAGER: 본인 휴가만 볼 수 있다.
- EXTERNAL_PARTNER: 내부 휴가 캘린더에 접근할 수 없다.

## LEAD 범위 계산

LEAD 범위는 `Team.leadUserId`와 `Team.parentTeamId`를 기준으로 서버에서 계산한다.

- 담당 팀 포함
- 하위 팀 포함
- 비활성 팀 제외
- 비활성/삭제 직원 제외
- 담당 범위 밖 직원은 DB query 단계에서 제외

클라이언트에 전체 직원 휴가 데이터를 내려준 뒤 필터링하지 않는다.

## 표시 정책

- 기본 표시 상태는 승인 완료 휴가다.
- 반려, 취소, 철회된 휴가는 기본 캘린더에 표시하지 않는다.
- 휴가 사유 원문, 증명자료, 관리자 메모는 캘린더에 표시하지 않는다.
- LEAD는 담당 범위 구성원의 휴가 유형과 일정만 확인한다.

## 회귀 보호

휴가 캘린더는 승인된 `LeaveRequest` 조회만 사용한다. 휴가 잔여 계산 helper와 1년 미만 직원 비례연차 계산 helper를 수정하지 않는다.
