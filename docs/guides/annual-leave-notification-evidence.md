# 연차 사용계획 고지 증적 메모

기준일: 2026-05-12

## 확인한 공식 기준

- 국가법령정보센터 근로기준법 제60조, 제61조: 시행 2025-10-23, 법률 제20520호.
- 고용노동부 빠른인터넷상담의 근로기준법 제61조 안내.
- Context7: Next.js App Router Route Handler는 GET이 기본 캐시되지 않으며, 클라이언트 polling fetch에는 `cache: "no-store"`를 사용한다. Prisma는 중복 방지에 unique constraint, `upsert`, `createMany({ skipDuplicates: true })`, JSON null 처리를 공식 패턴으로 안내한다.

## 구현 기준

- 1년 이상 연차는 사용기간 만료 6개월 전 기준 10일 이내 1차 촉구, 미제출 시 사용기간 만료 2개월 전까지 2차 통보가 필요한 흐름으로 기록한다.
- 1년 미만 근로자의 제60조제2항 연차는 최초 1년 근로기간 종료 전 3개월 기준 10일 이내 1차 촉구, 미제출 시 1개월 전까지 2차 통보 흐름으로 기록한다.
- 웹 알림은 내부 고지와 열람 증적을 남기는 장치다. 법정 "서면 촉구/통보" 효력을 웹 알림만으로 충족한다고 단정하지 않는다.
- 법적 효력 판단, 전자문서 동의 방식, PDF/엑셀 보관 양식, 관리자 2차 지정 통보 문안은 실제 운영 전 노무/법무 검토가 필요하다.

## 저장 증적

`AnnualLeavePromotionNotice`는 대상자, 고지 유형, 법령/정책 버전, 고지 내용, 미사용 연차 수량, 사용 가능 기간, 제출 요청 기한, 생성/표출/열람/제출 시각, 재고지 여부, 관리자 확인 필드를 보관한다. 사용자가 알림센터나 NotificationBell CTA로 알림을 읽으면 `Notification.readAt`과 연결된 고지의 `readAt`을 함께 기록한다.
