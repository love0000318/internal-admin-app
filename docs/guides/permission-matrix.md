## 보안 원칙

- 마지막 ACTIVE OWNER는 권한 제거 또는 비활성화할 수 없습니다.
- 자기 자신의 OWNER 권한 제거, role 강등, 비활성화는 차단합니다.
- CSV export와 AuditLog export는 Step-up 재인증이 필요합니다.
- LEAD는 담당 범위 밖 직원, 휴가, 첨부파일에 접근할 수 없습니다.
- MANAGER는 타인 HR 민감정보와 관리자 기능에 접근할 수 없습니다.
- EXTERNAL_PARTNER는 내부 기능 접근이 불가합니다.
