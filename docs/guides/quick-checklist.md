# 운영 빠른 체크리스트

배포 또는 시연 직후 운영자가 빠르게 확인할 항목이다.

## 환경변수

- [ ] `DATABASE_URL`이 운영 DB를 가리킨다.
- [ ] `APP_BASE_URL`이 실제 서비스 주소다.
- [ ] `SESSION_SECRET`이 충분히 길고 예측 불가능하다.
- [ ] `ENCRYPTION_SECRET`이 설정되어 있고 `SESSION_SECRET`과 다르다.
- [ ] cron endpoint를 사용할 경우 `CRON_SECRET`이 설정되어 있다.
- [ ] 첨부파일을 사용할 경우 `PRIVATE_UPLOAD_DIR`와 `MAX_LEAVE_ATTACHMENT_SIZE_MB`를 확인했다.

## DB와 실행

- [ ] `pnpm db:deploy` 또는 환경에 맞는 migration을 적용했다.
- [ ] `pnpm db:seed`를 실행했다.
- [ ] `pnpm preflight`가 통과했다.
- [ ] `pnpm build`가 통과했다.

## 기본 운영

- [ ] OWNER가 로그인할 수 있다.
- [ ] 조직/팀을 생성하거나 확인했다.
- [ ] 직원 초대 링크를 만들 수 있다.
- [ ] 직원 가입이 가능하다.
- [ ] 직원별 휴가 보유 현황이 보인다.

## HR

- [ ] HR 엑셀 원본은 `private/imports` 아래에만 둔다.
- [ ] `pnpm hr:import private/imports/employee-master.xlsx`를 실행할 수 있다.
- [ ] 사전 직원 프로필과 온보딩 상태를 확인했다.
- [ ] 직원이 `/profile/confirm`에서 정보를 확인할 수 있다.

## 휴가

- [ ] 연차/반차 요청이 가능하다.
- [ ] 맞춤휴가 지급과 요청이 가능하다.
- [ ] 생일 반차 dry-run이 동작한다.
- [ ] OWNER 또는 담당 LEAD가 휴가를 승인/반려할 수 있다.
- [ ] `pnpm leave:ledger:validate` 결과 issue가 없다.

## 증명자료/캘린더/리포트

- [ ] 증명자료가 public 폴더가 아닌 private storage에 저장된다.
- [ ] 권한 없는 사용자는 첨부파일을 다운로드할 수 없다.
- [ ] 휴가 캘린더에 사유와 증명자료가 노출되지 않는다.
- [ ] 관리자 리포트 CSV에 민감정보가 없다.

## 알림/Job/보안

- [ ] `/notifications`에서 내 알림만 보인다.
- [ ] `/admin/jobs`는 OWNER만 접근한다.
- [ ] 주요 Job dry-run을 실행했다.
- [ ] AuditLog에 token, fileKey, 주민번호, 계좌번호 원문이 없다.
## 3차 모바일 UX 빠른 확인

- [ ] 390px 모바일 화면에서 로그인 form이 화면 밖으로 벗어나지 않는다.
- [ ] 390px 모바일 화면에서 초대 가입 form과 가입 인증 코드 입력이 1열로 표시된다.
- [ ] 390px 모바일 화면에서 내 휴가 화면의 긴 표는 내부 가로 스크롤로 처리된다.
- [ ] 390px 모바일 화면에서 새 휴가 요청 form의 입력칸과 제출 버튼이 전체 폭에 맞는다.
- [ ] 휴가 관리 설정 탭은 모바일에서 가로 스크롤되고 한글이 세로로 깨지지 않는다.
- [ ] 휴가 유형 목록은 모바일에서 카드형 또는 내부 스크롤형으로 읽을 수 있다.
- [ ] 알림센터는 모바일에서 카드형 목록과 가로 스크롤 필터로 표시된다.
- [ ] 모든 로그인 후 화면 우측 상단에 알림 아이콘이 보인다.
- [ ] 읽지 않은 알림이 있으면 빨간 badge와 진동 animation이 보인다.
- [ ] 휴가 캘린더에서 연차는 파란색, 반차는 주황색, 유형 숨김 휴가는 중립색이다.

## 외부 캘린더 구독 빠른 확인

- [ ] `/leaves/calendar/settings`에서 구독 링크를 생성한다.
- [ ] 생성된 ICS URL을 브라우저에서 열어 `BEGIN:VCALENDAR` 응답을 확인한다.
- [ ] Google Calendar 웹에서 “URL로 추가”가 가능한지 확인한다.
- [ ] Apple Calendar 구독 캘린더 추가 안내를 운영자에게 공유한다.
- [ ] Samsung Calendar는 필요 시 Google Calendar 구독 후 계정 동기화를 안내한다.
- [ ] 비활성화 후 같은 URL이 404로 차단되는지 확인한다.
## 모바일 UX 빠른 확인

- [ ] 모바일 390px에서 로그인 화면이 가로 스크롤 없이 표시된다.
- [ ] 모바일 390px에서 초대 가입 화면의 가입 인증 코드 입력이 명확하다.
- [ ] 로그인 후 상단 알림 아이콘이 모든 protected page에 표시된다.
- [ ] 읽지 않은 알림이 있으면 빨간 badge와 진동이 표시된다.
- [ ] 휴가 관리 설정 탭이 한 글자씩 세로로 깨지지 않는다.
- [ ] 휴가 유형 목록은 모바일에서 카드형, PC에서 table로 표시된다.
- [ ] 휴가 요청 화면의 입력 필드와 제출 버튼이 모바일 1열로 표시된다.
- [ ] 연차 사용계획 화면은 시작일, 종료일, 사용 형태, 자동 계산 수량 순서로 표시된다.
- [ ] 휴가 캘린더에서 연차/반차/생일 반차/비공개 휴가 색상 규칙이 적용된다.
