# 휴가 엑셀 업로드 최종 운영 가이드

이 문서는 총괄 관리자(OWNER)가 실제 운영 화면에서 휴가 사용 상세 내역과 월별 연차 사용 내역을 안전하게 반영하기 위한 최종 절차입니다.

실제 개인정보가 포함된 엑셀 파일은 GitHub, public 폴더, 문서 저장소에 올리지 않습니다. 파일은 운영 화면에서만 업로드하고, 반영 전 미리보기와 검증 결과를 반드시 확인합니다.

## 1. 사전 준비

1. OWNER 계정으로 로그인합니다.
2. `/admin/leaves/import`에 접근합니다.
3. 업로드할 파일이 최신인지 확인합니다.
4. 월별 연차 사용 내역 파일과 휴가 사용 상세 내역 파일을 구분합니다.
5. 직원 사번, 이름, 회사내이름이 시스템 직원 정보와 맞는지 확인합니다.
6. Step-up 재인증을 수행할 수 있는지 확인합니다.

## 2. 권장 반영 순서

운영 반영은 다음 순서를 권장합니다.

1. 휴가 사용 상세 내역 파일을 먼저 업로드합니다.
2. 시스템에 사용, 승인대기, 취소 이력을 반영합니다.
3. 월별 연차 사용 내역 파일을 업로드합니다.
4. 엑셀 잔여 연차와 시스템 잔여 연차를 비교합니다.
5. 차이가 있는 직원만 보정합니다.

상세 사용 내역이 먼저 반영되어야 시스템의 사용량과 잔여가 계산됩니다. 그 후 월별 잔여 연차 파일과 비교해야 조정값이 정확해집니다.

## 3. 휴가 사용 상세 내역 업로드

1. 업로드 유형에서 `휴가 사용 상세 내역` 또는 `자동 감지`를 선택합니다.
2. `.xlsx` 파일을 선택합니다.
3. 미리보기에서 header row 감지 결과를 확인합니다.
4. 날짜 변환 결과를 확인합니다.
5. 직원 매칭 결과를 확인합니다.
6. 휴가 유형 매핑 결과를 확인합니다.
7. 상태 매핑 결과를 확인합니다.
8. UNKNOWN 상태 row, 미매칭 직원 row, 중복 의심 row를 확인합니다.
9. 오류 row가 있으면 반영하지 않고 파일 또는 매핑을 정리합니다.
10. Step-up 재인증 후 최종 반영합니다.

## 4. 월별 연차 사용 내역 업로드

1. 상세 파일 반영이 끝난 뒤 진행합니다.
2. 업로드 유형에서 `월별 연차 사용 내역` 또는 `자동 감지`를 선택합니다.
3. `.xlsx` 파일을 선택합니다.
4. 직원 매칭 결과를 확인합니다.
5. 엑셀 잔여 연차와 시스템 잔여 연차의 차이를 확인합니다.
6. 차이가 0인 직원은 조정하지 않습니다.
7. 차이가 있는 직원만 보정 대상인지 확인합니다.
8. Step-up 재인증 후 필요한 조정만 반영합니다.

## 5. 자동 반영하지 않는 row

다음 row는 자동 반영하지 않습니다.

- 직원이 미매칭인 row
- 휴가 유형이 매핑되지 않은 row
- 상태가 UNKNOWN인 row
- 중복 의심 row
- 이미 같은 batch에서 반영된 row
- 오류가 있는 row

취소 상태 row는 사용량으로 차감하지 않습니다. 승인대기 row는 사용완료가 아니라 pending으로만 반영합니다.

## 6. 반영 후 검증

반영 후 다음을 확인합니다.

1. 구성원 휴가 현황에서 직원별 잔여 연차를 확인합니다.
2. import batch 상세의 reconciliation 결과를 확인합니다.
3. 엑셀 잔여와 시스템 잔여의 차이가 있는 직원을 확인합니다.
4. 승인대기, 사용완료, 조정 수량이 예상과 맞는지 확인합니다.
5. LeaveLedger에 import source와 idempotencyKey가 남았는지 확인합니다.
6. AuditLog에 import 요약이 기록되었는지 확인합니다.

## 7. 금지 사항

- 운영 DB에서 `prisma migrate reset`을 실행하지 않습니다.
- 실제 엑셀 원본을 GitHub에 커밋하지 않습니다.
- 실제 엑셀 원본을 public 폴더에 저장하지 않습니다.
- 미리보기 없이 자동 반영하지 않습니다.
- Step-up 없이 최종 반영하지 않습니다.
- UNKNOWN 상태 row를 자동 승인 처리하지 않습니다.
- 취소된 휴가를 used로 차감하지 않습니다.
- 중복 차감을 허용하지 않습니다.
- secret, token, DATABASE_URL을 문서에 기록하지 않습니다.
