# 대표 시작 가이드

비개발자인 대표가 처음 서비스를 설정할 때 따라가는 순서입니다.

## 1. 서비스 접속 주소 확인

운영 담당자에게 서비스 주소를 받습니다.

예:

```text
https://internal.example.com
```

## 2. 대표 계정 생성

운영 담당자가 전달한 OWNER 초대 링크를 엽니다.

입력:

- 이름
- 전화번호
- 비밀번호
- 비밀번호 확인
- 본인인증 값

비밀번호는 영문, 숫자, 특수문자를 포함해 8자 이상이어야 합니다.

## 3. 첫 로그인

가입이 끝나면 `/dashboard`로 이동합니다. 이후에는 `/login`에서 전화번호와 비밀번호로 로그인합니다.

## 4. 회사 조직 생성

좌측 메뉴 `조직 구성 및 직원 초대`로 이동합니다.

1. `조직/팀 관리`를 엽니다.
2. 팀명을 입력합니다.
3. 필요한 경우 상위 팀과 팀 리드를 지정합니다.
4. 저장합니다.

## 5. 리드/매니저 초대

`직원 초대` 화면에서 직원 정보를 입력합니다.

- 이름
- 이메일
- 직급
- 역할: 중간 관리자 또는 일반 관리자
- 소속 팀
- 입사일
- 생일

초대 생성 후 표시되는 링크를 직원에게 전달합니다.

## 6. 직원 정보 확인

`직원 목록`에서 직원의 팀, 직급, 입사일, 생일, 상태를 확인합니다.

## 7. 회사 휴일 등록

`휴가 관리 설정 > 회사 휴일 관리`에서 회사 휴일을 등록합니다. 등록된 휴일은 휴가 일수 계산에서 제외됩니다.

## 8. 휴가 정책 확인

`휴가 관리 설정`에서 휴가 유형별 설정을 확인합니다.

- 연차
- 반차
- 예비군
- 병가
- 경조사

## 9. 예비군/병가/경조사 정책 설정

각 정책에서 연차 차감 여부와 증빙 필요 여부를 설정합니다.

## 10. 직원에게 초대 링크 전달

초대 링크는 1회만 사용할 수 있습니다. 링크를 분실하면 초대 재발급을 사용합니다.

## 11. 직원 가입 확인

직원이 가입하면 직원 목록에서 상태가 `활성`으로 표시됩니다.

## 12. 첫 휴가 요청 테스트

직원 계정으로 로그인해 `휴가 보유 현황 및 요청`에서 새 휴가 요청을 생성합니다.

## 13. 첫 휴가 승인 테스트

OWNER 계정으로 `휴가 승인 요청 사항`에 들어가 방금 생성된 요청을 승인합니다.

## 14. 감사 로그 확인

`감사 로그`에서 초대, 사용자 생성, 휴가 요청, 휴가 승인 이력이 기록되어 있는지 확인합니다.
