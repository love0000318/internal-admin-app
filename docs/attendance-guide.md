# 근태 사용 가이드

## 내 근태 이력

직원은 `/attendance/history`에서 본인의 월별 근태 기록과 수정 요청 상태를 확인한다.

## 수정 요청

- 마감 전 월은 직원이 신규 근태 수정 요청을 등록할 수 있다.
- 마감 완료 월은 신규 수정 요청이 차단된다.
- 마감 완료 월에서 오류가 있으면 관리자에게 문의한다.

## 관리자 월별 마감

OWNER와 LEAD는 `/admin/attendance/monthly`에서 월별 근태 요약을 확인한다.

- OWNER: 전체 조회, Step-up 후 마감/해제 가능
- LEAD: 담당 팀과 하위 팀만 조회 가능
- MANAGER: 관리자 마감 화면 접근 불가
- EXTERNAL_PARTNER: 내부 근태 접근 불가

## 휴가와의 관계

근태 요약은 승인된 LeaveRequest를 조회해 휴가일을 표시한다. 휴가 잔여 계산 helper는 수정하거나 재계산하지 않는다.
