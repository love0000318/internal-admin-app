# 2차 9단계 캘린더 구현 업데이트

## 구현 완료

- `/leaves/calendar` 내부 휴가 캘린더 화면
- 월간 보기와 목록 보기
- 기준 월, 팀, 직원, 휴가 유형, 상태, 범위 필터
- OWNER 전체 휴가 표시
- LEAD 담당 팀 및 하위 팀 휴가 표시
- MANAGER 자기 휴가 및 같은 팀 공개 휴가 표시
- `PUBLIC_WITH_TYPE`, `PUBLIC_AS_LEAVE`, `PRIVATE_TO_APPROVERS` 공개 범위 적용
- PENDING 휴가를 본인/승인권자에게만 표시
- 반차 오전/오후 표시
- 상세 링크 권한 분기

## 보안 원칙

캘린더 DTO에는 휴가 사유, 증명자료 상태, 첨부파일 정보, 검토 코멘트가 포함되지 않습니다. 서버 helper에서 권한 필터링을 완료한 뒤 화면에 전달합니다.

## 후순위

- 외부 캘린더 연동
- iCal feed
- 주간 보기
- 실제 차감일 기준 표시 개선
- 캘린더에서 휴가 요청 생성
- 캘린더에서 승인/반려 처리
