# 관리자 리포트 수동 테스트

## 기본 접근

- [ ] OWNER로 로그인한다.
  - 기대 결과: `/admin/reports`에 접근할 수 있다.
- [ ] MANAGER로 `/admin/reports`에 직접 접근한다.
  - 기대 결과: 접근 권한 없음 또는 로그인/권한 차단 화면이 표시된다.

## 휴가 리포트

- [ ] 휴가 사용 현황 리포트에서 기준 연도와 상태 필터를 적용한다.
  - 기대 결과: 조건에 맞는 휴가 요청만 표시된다.
- [ ] 휴가 장부 리포트를 조회한다.
  - 기대 결과: LeaveLedger 이벤트가 표시되고 metadata 전체나 idempotencyKey는 보이지 않는다.
- [ ] 맞춤휴가 지급 리포트와 생일 반차 지급 리포트를 조회한다.
  - 기대 결과: 지급, 사용, 잔여 수량이 표시된다.

## HR/증명자료 리포트

- [ ] 증명자료 제출 현황 리포트를 조회한다.
  - 기대 결과: fileKey, private path, 다운로드 URL은 표시되지 않는다.
- [ ] HR 온보딩 리포트를 조회한다.
  - 기대 결과: 전화번호는 마스킹되고 주민등록번호/계좌번호는 표시되지 않는다.
- [ ] 직원 프로필 확인 현황 리포트를 조회한다.
  - 기대 결과: 수정 요청 상세 원문 대신 상태별 개수만 표시된다.

## CSV Export

- [ ] 각 리포트에서 CSV 내보내기를 실행한다.
  - 기대 결과: CSV 파일이 다운로드된다.
- [ ] CSV를 열어 민감정보를 확인한다.
  - 기대 결과: 주민등록번호, 계좌번호, token/tokenHash, passwordHash, fileKey, private path가 없다.
- [ ] AuditLog를 확인한다.
  - 기대 결과: `REPORT_EXPORTED`가 기록되고 CSV 본문은 저장되지 않는다.
