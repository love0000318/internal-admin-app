# 3차 개발 후보

2차 고도화에서는 실제 운영 가능한 내부 HR·휴가 관리 흐름을 우선 정리했다. 아래 항목은 3차 이후 별도 범위로 검토한다.

## 알림과 외부 연동

- 실제 이메일 발송
- 카카오톡 알림
- Slack 알림
- SMS 알림
- 보안 이벤트 알림

## 캘린더와 협업 연동

- Google Calendar 연동
- Outlook 연동
- iCal feed
- 외부 캘린더 구독

## 파일과 문서

- 실제 S3/GCS/Azure Blob 파일 스토리지
- 바이러스 검사
- OCR
- 전자계약
- 근로계약서 전자서명

- 연차수당 정산
- 퇴사자 정산
