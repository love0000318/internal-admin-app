# 직원 사용 가이드

## 1. 초대 링크 받기

대표 또는 관리자가 전달한 초대 링크를 엽니다.

초대 링크는 한 번만 사용할 수 있고 만료 시간이 있습니다.

## 2. 회원가입

입력:

- 이름
- 전화번호
- 비밀번호
- 비밀번호 확인
- 본인인증 값

비밀번호는 영문, 숫자, 특수문자를 포함해 8자 이상이어야 합니다.

## 3. 로그인

`/login`에서 전화번호와 비밀번호로 로그인합니다.

## 4. 내 휴가 보유 현황 확인

좌측 메뉴 `휴가 보유 현황 및 요청`에서 다음을 확인합니다.

- 총 부여 휴가
- 사용 완료 휴가
- 승인 대기 휴가
- 사용 가능 잔여 휴가

## 5. 연차 요청

`새 휴가 요청하기`를 누르고 휴가 유형을 `연차`로 선택합니다.

시작일과 종료일을 선택하면 토/일과 회사 휴일을 제외한 일수로 계산됩니다.

## 6. 반차 요청

휴가 유형을 `반차`로 선택합니다.

- 날짜는 하루만 선택합니다.
- 오전 또는 오후를 선택합니다.
- 요청 일수는 0.5일입니다.

## 7. 예비군/병가/경조사 요청

휴가 유형을 선택하고 기간과 사유를 입력합니다. 정책상 증빙이 필요한 경우 첨부 URL을 입력해야 합니다.

## 8. 요청 상태 확인

내 휴가 목록에서 상태를 확인합니다.

- 승인 대기
- 승인 완료
- 반려
- 취소
- 철회

## 9. 요청 철회 방법

`승인 대기` 상태의 요청 상세 화면에서 `요청 철회`를 누릅니다.

이미 승인된 휴가는 직원이 직접 철회할 수 없습니다. 관리자에게 별도 문의합니다.

## 10. 비밀번호 관리 주의사항

비밀번호를 다른 사람에게 공유하지 않습니다. 비밀번호 분실/변경 기능은 2차 개발 후보입니다.
