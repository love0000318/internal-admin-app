# 직원 오픈 최종 안내문

이 문서는 직원에게 실제로 전달할 수 있는 최종 안내문이다. `{초대 링크}`, `{가입 인증 코드}`, `{문의처}`는 직원별로 채워서 전달한다. 가입 인증 코드와 초대 링크는 공개 채널에 공유하지 않는다.

## 직원 발송 메시지

```txt
안녕하세요.

사내 관리 서비스 가입 안내드립니다.

아래 초대 링크로 접속해 가입을 완료해 주세요.

초대 링크:
{초대 링크}

가입 인증 코드:
{가입 인증 코드}

가입 절차:
1. 초대 링크 접속
2. 이름, 전화번호, 비밀번호 입력
3. 가입 인증 코드 입력
4. 가입 완료 후 로그인

가입 후 사용할 수 있는 기능:
- 내 휴가 보유 현황 확인
- 휴가 요청
- 휴가 승인 상태 확인
- 출근/퇴근 기록, 운영 범위에 포함된 경우
- 알림 확인

가입 인증 코드는 1회만 사용할 수 있으니 외부에 공유하지 말아 주세요.
공용 PC에서는 자동 로그인 유지를 선택하지 않는 것을 권장합니다.

문제가 발생하면 관리자에게 문의해 주세요.

문의:
{문의처}
```

## 서비스 소개

Internal Ops는 사내 운영을 위한 관리 서비스다. 직원은 로그인 후 내 휴가 보유 현황, 휴가 요청, 승인 상태, 알림을 확인할 수 있다. 근태 기능이 운영 범위에 포함된 경우 출근/퇴근 기록과 근태 이력도 확인할 수 있다.

## 가입 방법

1. 관리자가 전달한 초대 링크에 접속한다.
2. 가입 인증 코드를 입력한다.
3. 이름, 전화번호, 비밀번호를 입력한다.
4. 가입을 완료한 뒤 로그인한다.

가입 인증 코드는 1회만 유효하다. 코드가 만료되었거나 분실된 경우 관리자에게 재발급을 요청한다.

## 로그인 방법

- 운영 URL: `https://interal-admin-app.vercel.app`
- 전화번호와 비밀번호로 로그인한다.
- 개인 기기에서는 `이 기기에서 자동 로그인 유지`를 사용할 수 있다.
- 공용 PC나 공유 기기에서는 자동 로그인 유지를 사용하지 않는다.
- 사용 후에는 반드시 로그아웃한다.

## 휴가 요청 방법

1. 로그인 후 내 휴가 화면으로 이동한다.
2. 잔여 휴가를 확인한다.
3. 휴가 요청 화면에서 휴가 유형과 날짜를 입력한다.
4. 반차인 경우 오전/오후를 선택한다.
5. 요청 후 승인 상태를 확인한다.

## 휴가 승인 상태 확인

- 내 휴가 요청 목록에서 승인 대기, 승인 완료, 반려, 취소 상태를 확인한다.
- 승인/반려 알림은 알림센터에서도 확인할 수 있다.

## 출근/퇴근 기록 방법

근태 기능이 직원 오픈 범위에 포함된 경우:

1. 근태 화면으로 이동한다.
2. 출근 시 출근 버튼을 누른다.
3. 퇴근 시 퇴근 버튼을 누른다.
4. 근태 이력에서 기록을 확인한다.

근태 메뉴가 보이지 않는 경우 이번 오픈 범위에서 제외되었을 수 있으므로 관리자에게 문의한다.

## 알림 확인 방법

로그인 후 우측 상단 알림 아이콘을 누르면 알림센터로 이동한다. 읽지 않은 알림이 있으면 빨간 표시가 보인다.

## 모바일 사용 안내

모바일 브라우저에서 가입, 로그인, 휴가 요청, 알림 확인을 사용할 수 있다. 화면이 깨지거나 버튼이 보이지 않으면 기기명, 브라우저, 화면 스크린샷을 관리자에게 전달한다.
