# 첫 주 운영 모니터링

직원 오픈 후 1주일 동안 매일 확인할 항목이다. 문제가 발생하면 `docs/employee-open-issue-response.md`와 `docs/production-incident-runbook.md`를 따른다.

## 매일 확인

### 가입/로그인

- [ ] 신규 가입 실패 문의 여부
- [ ] 초대 링크 만료/재발급 요청 여부
- [ ] 가입 인증 코드 오류 문의 여부
- [ ] 로그인 실패 증가 여부
- [ ] 계정 비활성/권한 오류 문의 여부

### 휴가

- [ ] 휴가 요청 생성 여부
- [ ] 승인/반려 정상 처리 여부
- [ ] 승인 대기 요청 누락 여부
- [ ] 휴가 잔여 이상 문의 여부
- [ ] 생일 반차/맞춤휴가 표시 문의 여부

### 근태

근태 기능을 운영 범위에 포함한 경우:

- [ ] 출근 기록 정상 여부
- [ ] 퇴근 기록 정상 여부
- [ ] 중복 출근 차단 여부
- [ ] 퇴근 누락자 여부
- [ ] 근태 수정 요청 발생 여부

근태 기능이 제외된 경우:

- [ ] 근태 메뉴/기능 제외 안내가 직원에게 전달되었는지 확인

### 알림/모바일

- [ ] 알림센터 동작 여부
- [ ] 읽지 않은 알림 badge 표시 문의 여부
- [ ] 모바일 화면 깨짐 문의 여부
- [ ] 버튼/탭/테이블 overflow 문의 여부

### 보안/시스템

- [ ] AuditLog 고위험 이벤트
- [ ] 보안 대시보드 CRITICAL/HIGH 이벤트
- [ ] Step-up 실패 증가 여부
- [ ] 비인가 접근 차단 이벤트
- [ ] Vercel 배포/서버 오류
- [ ] Neon DB 오류
- [ ] 외부 알림 실패 여부

### 직원 문의

- [ ] 신규 문의 수
- [ ] 반복 문의 유형
- [ ] 긴급 대응 필요 여부
- [ ] 문서 보완 필요 여부

## 주간 확인
