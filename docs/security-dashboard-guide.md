# 보안 대시보드 가이드

## 목적

`/admin/security`는 OWNER가 최근 보안 이벤트를 빠르게 확인하기 위한 운영 화면입니다.

## 접근 권한

- OWNER만 접근할 수 있습니다.
- LEAD, MANAGER, EXTERNAL_PARTNER는 접근할 수 없습니다.

## 표시 항목

요약 카드:

- 최근 24시간 로그인 실패 수
- 최근 24시간 로그인 차단 수
- 최근 7일 권한 변경 수
- 최근 7일 OWNER 관련 이벤트 수
- 최근 7일 초대 재발급 수
- 최근 7일 CSV export 수
- 최근 7일 첨부파일 다운로드 수
- 최근 7일 비인가 접근 차단 수
- 최근 실패한 Job 수
- 최근 Step-up 실패 수

목록:

- 최근 CRITICAL 이벤트
- 최근 HIGH 이벤트
- 최근 로그인 실패
- 최근 권한 변경
- 최근 리포트 export
- 최근 초대 재발급
- 최근 첨부파일 다운로드
- 최근 Job 실패

## 운영 방법

매일 CRITICAL/HIGH 이벤트를 확인하고, OWNER 권한 변경, 리포트 export, 초대 재발급, 반복 로그인 차단이 있으면 원인을 확인합니다.

## 주의

보안 대시보드는 앱 내부 이벤트를 보여줍니다. GitHub, Vercel, Neon 같은 인프라 권한 오남용은 별도의 접근권한 통제와 감사 절차가 필요합니다.
