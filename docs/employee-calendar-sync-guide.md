# 직원용 외부 캘린더 연동 안내

외부 캘린더 연동은 구독 방식의 단방향 동기화입니다.

Internal Ops에서 승인된 휴가와 이벤트가 외부 캘린더에 표시됩니다. 외부 캘린더에서 직접 추가하거나 수정한 일정은 Internal Ops에 반영되지 않습니다.

캘린더 앱의 갱신 주기에 따라 일정 반영 또는 삭제까지 시간이 걸릴 수 있습니다.

구독 URL은 개인 일정 정보를 볼 수 있는 링크이므로 외부에 공유하지 마세요. 유출이 의심되면 즉시 URL을 재발급하세요.

## 사용 방법

1. Internal Ops에 로그인한다.
2. 내 프로필 또는 휴가 캘린더에서 외부 캘린더 연동 화면으로 이동한다.
3. 사용할 캘린더 프로그램을 선택한다.
4. 구독 URL을 생성한다.
5. URL을 복사해 외부 캘린더 앱에 추가한다.

## 프로그램별 안내

### Google Calendar

Google Calendar에서 다른 캘린더 추가 → URL로 추가를 선택하고 구독 URL을 붙여넣습니다.

### Apple Calendar

iPhone 또는 macOS 캘린더 앱에서 새 캘린더 구독 추가를 선택하고 구독 URL을 입력합니다.

### Samsung Calendar

직접 URL 구독이 제한될 수 있습니다. Google Calendar에 구독 URL을 추가한 뒤 Samsung Calendar에서 Google 계정을 동기화하세요.

### Outlook Calendar

Outlook에서 인터넷 캘린더 구독 또는 웹의 구독 캘린더 추가 메뉴를 사용합니다.

### 기타 iCal 지원 앱

iCal 또는 ICS URL 구독을 지원하는 앱에서 사용할 수 있습니다.

## URL 재발급과 연동 해제

- URL 재발급을 하면 기존 URL은 더 이상 사용할 수 없습니다.
- 연동 해제를 하면 기존 URL 접근이 차단됩니다.
- 외부 캘린더 앱에 이미 추가한 구독 캘린더는 앱에서 직접 삭제해야 할 수 있습니다.
