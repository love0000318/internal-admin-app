# 직원 FAQ

직원 오픈 후 자주 받을 수 있는 질문과 답변이다.

## 초대 링크가 만료되었다고 나와요.

초대 링크는 만료 시간이 있고 한 번 사용하면 다시 사용할 수 없습니다. 관리자에게 새 초대 링크와 새 가입 인증 코드를 요청해 주세요.

## 가입 인증 코드를 잃어버렸어요.

가입 인증 코드는 생성 직후 한 번만 표시됩니다. 분실한 경우 관리자가 초대를 재발급해야 합니다. 이전 코드는 더 이상 사용할 수 없습니다.

## 가입 인증 코드가 맞지 않다고 나와요.

오타, 만료, 이미 사용된 코드, 이전 초대 코드 사용이 원인일 수 있습니다. 계속 실패하면 관리자에게 재발급을 요청해 주세요.

## 비밀번호를 잊어버렸어요.

현재 운영 정책에 따라 관리자 지원이 필요할 수 있습니다. 관리자에게 문의해 계정 상태와 재가입 또는 비밀번호 재설정 절차를 안내받아 주세요.

## 휴가 잔여가 이상해요.

휴가 잔여는 부여, 사용, 승인 대기, 취소, 반려 이력에 따라 계산됩니다. 이상해 보이면 관리자에게 문의해 주세요. 요청 시 어떤 휴가 유형과 날짜가 이상한지 함께 알려 주세요.

## 휴가 요청을 잘못했어요.

승인 대기 상태라면 요청을 철회할 수 있습니다. 이미 승인된 휴가는 관리자에게 취소 또는 변경 가능 여부를 문의해 주세요.

## 휴가가 승인되지 않았는데 시작일이 지났어요.

운영 정책에 따라 시작일이 지난 승인 대기 휴가는 자동 확정될 수 있습니다. 알림센터와 내 휴가 요청 상세에서 상태를 확인해 주세요.

## 출근 버튼을 잘못 눌렀어요.

근태 기능을 운영 중이라면 근태 수정 요청 또는 관리자 문의를 통해 정정 절차를 진행합니다. 잘못 누른 시간과 사유를 관리자에게 알려 주세요.

## 퇴근을 깜빡했어요.

근태 이력에서 누락 여부를 확인하고 관리자에게 문의해 주세요. 근태 수정 요청 기능이 운영 중이면 해당 기능으로 요청합니다.

## 모바일 화면이 깨져 보여요.

브라우저 새로고침 후 다시 확인해 주세요. 계속 문제가 있으면 기기명, 브라우저, 깨진 화면 URL, screenshot을 관리자에게 전달해 주세요.

## 알림이 안 보여요.

우측 상단 알림 아이콘 또는 알림센터를 확인해 주세요. 특정 이벤트의 알림이 보이지 않으면 어떤 작업 후 알림이 없었는지 관리자에게 알려 주세요.

## 자동 로그인 유지는 안전한가요?

개인 기기에서는 편의를 위해 사용할 수 있습니다. 공용 PC나 다른 사람과 함께 쓰는 기기에서는 사용하지 않는 것을 권장합니다. 로그아웃하면 자동 로그인 유지도 해제됩니다.

## 외부 캘린더에 휴가가 안 보여요.

외부 캘린더 구독 링크가 발급되어 있고, 캘린더 앱에 올바르게 추가되었는지 확인해 주세요. 외부 캘린더 앱은 구독 내용을 즉시 갱신하지 않을 수 있습니다. 계속 보이지 않으면 관리자에게 문의해 주세요.

## 초대 링크와 가입 인증 코드를 다른 사람에게 전달해도 되나요?

안 됩니다. 초대 링크와 가입 인증 코드는 본인 가입을 위해서만 사용해야 합니다. 외부에 공유하지 마세요.
